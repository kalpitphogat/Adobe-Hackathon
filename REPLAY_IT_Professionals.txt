#  * Not reported: content that is merely old. On a test site whose newest
#    date was 2018 and whose prices were "last reviewed January 2018", no
#    freshness finding fired; nor did extract.sd.contradicts_visible_content
#    when the schema foundingDate contradicted the founding year on the page.
#  * A bot-protection page ("you have been blocked") can be audited as if it
#    were the site's content; on pypi.org project pages and metacpan.org
#    (2026-09-26) such pages also produced soft-404, thin-content and
#    value-proposition findings.
#  * A server that answers with Brotli compression (content-encoding: br)
#    although it was asked for gzip/deflate is read as unreadable bytes, so
#    that page appears empty (seen on berkshirehathaway.com).
#  * A robots.txt Crawl-delay of about 4 s or more can exceed the default time
#    budget: add --time-budget 600 (see troubleshooting below).
#
# ---- IMPORTANT: RUN FROM THE MARKETPLACE ROOT -------------------------------
# A relative --out path only works when the current directory is the
# marketplace root (where marketplace.json is). From anywhere else, pass an
# absolute --out path, or the run stops with
# "error: no evidence bundle was produced".
#
# ---- TROUBLESHOOTING A JUDGE-CHOSEN URL -------------------------------------
# * Site whose robots.txt sets a large Crawl-delay (e.g. 4s+): the crawl can
#   outrun the default 300s budget and exit 1 without a report. Add
#   --time-budget 600 (an existing engine flag) to the orchestrate.py command.
# * Exit code is 0 whenever a schema-valid report was written; the outcome
#   (complete / partial / no_content_available) is in audit_status.
# * robots.txt is obeyed. A site that disallows crawling produces a report
#   that says it could not look, not an error.
# * Edge/CDN checks for named AI crawlers are off by default and appear in
#   limitations[] as "not assessed". Turn them on with --probe-bot-ua, only
#   for a site you own.
#
# ---- WHAT STAYS THE SAME ACROSS REPLAYS -------------------------------------
# The engine is deterministic: the same evidence gives the same findings (see
# the --bundle re-analysis above). Verify offline with:
#   python tests/run_offline.py
#   -> PASS: offline, deterministic, goldens current, control clean.
# That last comparison is byte for byte against goldens made with Python
# 3.11.15, and each golden records that version. On any other Python it
# prints "DRIFTED from golden" for all six sites and ends "FAILED (6)",
# while every other section still passes: the only field that differs is
# generator.tool_versions.python (checked 2026-09-26 on Windows with Python
# 3.12.5 and on Linux with 3.12.3).
# On a live URL, differences between runs come only from the site changing or
# the crawl sampling different pages; audited_at always changes. Example:
# docs.djangoproject.com gave the same 24 findings on 2026-09-23 and 2026-09-24.
# The agent's wording varies by model and run; the findings, severities, ICE
# scores and ranking do not.
